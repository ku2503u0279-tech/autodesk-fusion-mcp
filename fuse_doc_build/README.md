# PDF build kit

This folder rebuilds `../fusion_desk_setup/DESK_SETUP_DESIGNER_PORTFOLIO_AND_GUIDE.pdf`
from the same geometry as the Fusion models. Nothing here is hand-drawn: the
renders, the dimension lines and the catalogue tables all read from `parts.json`,
which is regenerated by `verify_fusion_scripts.py`.

## Rebuild

```bash
python3 -m venv .venv && .venv/bin/pip install reportlab pillow numpy pypdfium2
.venv/bin/python make_pdf.py
```

That writes the 21-page A4 landscape PDF in about 25 seconds.

## What is what

| file | job |
| --- | --- |
| `parts.json` | every part's bounding box, as reported by `verify_fusion_scripts.py` |
| `geometry.py` | turns those boxes into shaded solids (arches, decks, clamps, chalice, caddy) |
| `render3d.py` | small painter's-algorithm renderer with smooth shading, contact shadows and a silhouette pass |
| `ortho.py` | orthographic projection with a z-buffer, used for the plan / front / side dimension pages |
| `assets.py` | renders every illustration into `out/` |
| `catalog.py` | the 43-piece catalogue text and the table of contents |
| `pdfkit.py` | thin layout layer on reportlab (wrapping, tracked labels, fitted text) |
| `make_pdf.py` | the page-by-page document |

## Regenerating `parts.json`

```bash
cd ../fusion_desk_setup && python3 verify_fusion_scripts.py
cd ../fuse_doc_build && python3 - <<'PY'
import json, re, subprocess
out = subprocess.run(["python3", "../fusion_desk_setup/verify_fusion_scripts.py"],
                     capture_output=True, text=True).stdout
rows = []
for line in out.splitlines():
    m = re.search(r"Body_(\S+)\s+->\s+([\d.]+) x\s+([\d.]+) x\s+([\d.]+) mm\s+\| X\[\s*([-\d.]+),\s*([-\d.]+)\] Y\[\s*([-\d.]+),\s*([-\d.]+)\] Z\[\s*([-\d.]+),\s*([-\d.]+)\]", line)
    if m:
        rows.append(dict(name=m.group(1), size=[float(m.group(i)) for i in (2, 3, 4)],
                         x=[float(m.group(5)), float(m.group(6))],
                         y=[float(m.group(7)), float(m.group(8))],
                         z=[float(m.group(9)), float(m.group(10))]))
json.dump(rows, open("parts.json", "w"), indent=1)
print(len(rows), "parts")
PY
```

## Two things that will bite you

* reportlab colours are 0–1 floats. The palette here is shared with the renderer,
  so it is 0–255 tuples; every colour goes through `pdfkit.C()` before it reaches
  reportlab. Skip that and the whole page prints white.
* `pdfkit.para()` returns the baseline of the *next free line*. Every stacked
  block chains off the return value, so a label can never land on top of the
  value below it.
